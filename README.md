# Optimizator tăieri țeavă / profile

Calculator de debitare pentru bare liniare (țeavă, profile): găsește planul de tăiere cu cel mai puțin deșeu.

- Mai multe lungimi de bară (cantitate limitată sau nelimitată)
- Grosimea tăieturii (kerf) luată în calcul
- Import CSV (`lungime;buc;nume`)
- Fișă de debitare pentru operator, cu poziția fiecărui tăiș, gata de printat

Folosire: deschide `index.html` în browser. Nu necesită server sau instalare.
